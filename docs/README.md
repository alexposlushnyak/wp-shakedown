# Documentation

The docs follow the [Diátaxis](https://diataxis.fr/) layout: each document has one job.

| Section | Job | Documents |
|---|---|---|
| explanation/ | Why the tool is built the way it is | [Architecture](explanation/architecture.md) |
| adr/ | Decisions and the reasons behind them | [Index](adr/README.md) |
| tutorials/ | A first run, step by step | Not written yet |
| how-to/ | Recipes for specific tasks | Not written yet |
| reference/ | Commands, config, report schema | Not written yet |

Tutorials, how-to guides and reference describe a working tool, so they are written when there is one to describe.
